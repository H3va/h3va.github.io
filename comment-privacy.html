A random name, a real thought 🐾

No account, real name, or email is requested. Each post is assigned a random nickname and one of my pet photographs. Names are not verified identities and can change between posts.

Messages are public, including the text, assigned nickname, topic, pet avatar and posting date. Please do not include private details about yourself or others. Anonymous display does not make a comment untraceable.

When the service is connected, messages are stored in a Cloudflare D1 database. Cloudflare processes connection metadata, including IP addresses. This app uses a keyed hash of the connecting IP for a basic posting limit; it does not store the raw IP with the comment. Rate-limit entries for the current and previous ten-minute windows are retained and older entries are removed when new messages are submitted. Provider logs have separate retention.

Public messages remain until the owner deletes them. Contact hanwen040827@gmail.com with the message text and date to request removal. There is no self-service edit/delete feature in this version. The owner may remove spam, harassment, or private information.

No demo comments are published as real visitor feedback. If the service is disconnected or a submission fails, the page says so and does not claim to have saved your message.
